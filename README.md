# المحفظ

تطبيق أندرويد مجاني لتعلّم التجويد وحفظ القرآن الكريم والتفقّه في الدين.

## الإصدار ٢
- الحفظ مع الشيخ آيةً آية: الشيخ يقرأ، وأنت تردّد بصوتك، والكلمات الخاطئة تظهر بالأحمر مع ملاحظة التصحيح، والشيخ يعيد الآية حتى تتقنها.
- ٦ قرّاء (من EveryAyah).
- اختبار «كمّل الآية» لكل سورة، مع شهادة إتمام قابلة للمشاركة.
- مراجعة سورة أو جزء أو حزب أو ربع أو القرآن كاملًا، وتحديد المستوى.
- أكاديمية التجويد: ٦ مستويات بدروس وأمثلة صوتية واختبارات وشهادات.
- ٥ ثيمات: الزمرد الذهبي، ليالي رمضان، النعناع، الباستيل، نور.
- أحكام التجويد ملوّنة على كل آيات المصحف، مع لمس الكلمة لمعرفة حكمها.
- صوت موجّه: يقرأ الأسئلة والشروحات، ويشرح أخطاء التسميع وما يجب فعله.
- أكاديمية التجويد: ١٦ بابًا و٥١ درسًا، كل درس بفقرات صوتية متزامنة، وأمثلة بصوت الشيخ، واختبار إلزامي، وتمارين على آيات حقيقية، واختبار شامل وشهادة.
- المكتبة: ١٤ قسمًا و٦٥ درسًا: العقيدة، علوم القرآن، السيرة، الطهارة، الصلاة، الصيام، الزكاة، الحج، المعاملات، الأسرة، الحلال والحرام، الآداب، التزكية، الأذكار — باختبارات وشهادات.
- «أحاديث يحتاجها كل مسلم»: ٤٧ حديثًا من رياض الصالحين بعناوين وشروح.
- تدريب صوتي في كل باب تجويد على آيات مختارة.
- الأربعون النووية والقدسية بعنوان وشرح لكل حديث، ورياض الصالحين كاملًا، والتفسير الميسّر لكل آية.
- المسابقات: تحدي اليوم ومسابقات حسب الفرع ونقاط ومستويات.
- شهادات أفقية مزخرفة بنمطين قابلة للمشاركة كصورة عالية الدقة.

## التسجيلات الصوتية
`tool/audio_index.json` يربط كل مقطع صوتي بمكانه في التطبيق، و`RECORDING_GUIDE.md` يعرض نص كل فقرة.

## البناء والتحديثات
- رقم الإصدار والجديد فيه في `release.json`. لما الرقم يتغيّر ويترفع على `main`، GitHub Actions يبني APK موقّع وينشره في Releases باسم `v<الإصدار>`.
- كل النسخ موقّعة بنفس المفتاح، وهو محفوظ في GitHub Secrets (`ANDROID_KEYSTORE_B64` و`ANDROID_KEYSTORE_PASSWORD`) مش في الريبو. **ماتغيّرهوش أبدًا واحتفظ بنسخة منه**، وإلا التحديثات مش هتتثبت فوق النسخ القديمة.
- التطبيق بيسأل GitHub عن آخر نسخة عند الفتح وعند الرجوع له، ولو فيه أحدث بيعرض نافذة التحديث ويحمّل ويثبّت من جوّه التطبيق.
- عشان تنزّل تحديث: ارفع الملفات المتغيّرة، وبعدين زوّد رقم الإصدار في `release.json` (مثلًا `2.0.1`) واكتب الجديد في `notes`.

## المصادر والتراخيص
- نص المصحف: رواية حفص (رسم عثماني وإملائي) من مشروع quran-api.
- أحكام التجويد: quran-tajweed. التفسير الميسّر: مجمع الملك فهد. الأحاديث: hadith-json.
- الخطوط: Amiri وAmiri Quran وReadex Pro وAref Ruqaa، برخصة SIL OFL (ملفات الرخصة في `assets/fonts`).
- التلاوات: EveryAyah.com.
